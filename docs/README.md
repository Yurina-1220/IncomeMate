# IncomeMate Docs

IncomeMateの説明書・設計メモ・作業ログをまとめるフォルダです。

## まず見るファイル

| ファイル | 内容 |
|---|---|
| `concept.md` | IncomeMateの目的・背景・どんなアプリにしたいか |
| `roadmap.md` | 今後作る機能や開発の流れ |
| `setup.md` | PCで動かすための基本セットアップ |
| `incomemate-setup-guide.md` | 初心者向けの詳しいセットアップ手順 |
| `security.md` | `.env`や秘密キーなど、セキュリティ上の注意 |
| `glossary.md` | IncomeMate・開発・GitHub・Supabaseの用語集 |
| `development-guide.md` | 開発の進め方、バージョン管理、公開までの流れ |

## 作業ログ

作業した日ごとの記録は`logs/`に保存します。

| ファイル | 内容 |
|---|---|
| `logs/2.Aug.2026.md` | 2026年8月2日の作業ログ |
| `logs/11.Aug.2026.md` | 2026年8月11日の作業ログ |

## ファイル名のルール

今後は、見やすくするために以下のルールで保存します。

| 種類 | 保存場所 | ファイル名の例 |
|---|---|---|
| 日ごとの作業ログ | `docs/logs/` | `2.Aug.2026.md` |
| 手順書 | `docs/` | `setup.md` |
| 設計メモ | `docs/` | `concept.md` |
| セキュリティ説明 | `docs/` | `security.md` |

## バージョン名について

バージョン名は入れてよいです。
ただし、すべてのファイル名に入れると探しにくくなるため、以下のように管理します。

- 作業ログには「今日扱ったバージョン」を書く
- アプリ全体の正式なバージョンは、将来的に`package.json`やリリースノートで管理する
- 初期段階では`v0.1.0`のような小さな番号から始める

現在のおすすめは`v0.1.0-dev`です。

意味は「まだ開発中だけど、最初の土台を作っているバージョン」です。
