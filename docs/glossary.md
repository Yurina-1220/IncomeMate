# IncomeMate 用語集

Last updated: 18.Aug.2026

IncomeMateの作業中に出てくる言葉を、初心者向けにまとめたページです。

## 開発の基本用語

| 用語 | 意味 | IncomeMateでの役割 |
|---|---|---|
| アプリ | ユーザーが操作するソフトウェア | 収入・シフトを管理するIncomeMate |
| UI | 画面の見た目や操作部分 | ボタン、入力欄、カレンダー |
| フロントエンド | ユーザーが直接見る部分 | Reactで作った画面 |
| バックエンド | 裏側でデータ処理を行う部分 | API、認証、保存処理 |
| API | 画面と別のサービスをつなぐ窓口 | IncomeMateとSupabaseの接続 |
| データベース | データを整理して保存する場所 | 収入やシフトの保存 |
| クラウド | インターネット上の保存・実行環境 | Supabaseなど |
| ローカル | 自分のPC内で動かすこと | `localhost:3000`での確認 |
| PWA | Webサイトをアプリのように使う仕組み | スマホのホーム画面に追加 |

## 開発ツール

| 用語 | 意味 | 使う場所 |
|---|---|---|
| VS Code | コードを編集するアプリ | IncomeMateの編集 |
| ターミナル | 文字で操作する画面 | npm、Gitコマンドの実行 |
| PowerShell | Windowsのターミナル | VS Code内で使用 |
| Node.js | JavaScriptをPCで実行する環境 | 開発サーバーの起動 |
| npm | Node.jsのパッケージ管理ツール | `npm install`、`npm run dev` |
| パッケージ | 他の人が作った機能部品 | React、Next.jsなど |
| ビルド | 公開・実行できる形に変換する処理 | `npm run build` |
| テスト | 期待どおり動くか確認すること | 保存や画面表示の確認 |

## GitHub・バージョン管理

| 用語 | 意味 | IncomeMateでの使い方 |
|---|---|---|
| Git | ファイルの変更履歴を管理する仕組み | PCで変更を記録 |
| GitHub | Gitの履歴をオンライン保存するサービス | コードと資料の保管 |
| リポジトリ | プロジェクトの保管場所 | `Yurina-1220/IncomeMate` |
| ブランチ | 別々に作業するための履歴の枝 | 機能追加や資料編集 |
| commit | 変更をひとまとまりで記録すること | 何を変えたか残す |
| push | PCの変更をGitHubへ送ること | リモートへ保存 |
| pull | GitHubの変更をPCへ取り込むこと | PCとGitHubを同期 |
| Pull Request | 変更を確認してから統合する依頼 | `main`へ安全に反映 |
| main | 正式版として扱うブランチ | 動作確認済みの基準 |
| tag / release | バージョンに名前を付ける仕組み | `v0.1.0`など |

## Supabase・セキュリティ

| 用語 | 意味 | 注意点 |
|---|---|---|
| Supabase | データベース、認証、APIを提供するサービス | プロジェクトごとに管理 |
| SQL | データベースに命令する言語 | テーブル作成に使用 |
| テーブル | データを表形式で保存する場所 | `incomemate_snapshots` |
| `.env` | PCだけに置く秘密設定ファイル | GitHubへアップしない |
| `.env.example` | 必要な変数名だけを示す見本 | 値は空欄にする |
| APIキー | サービスへ接続するための鍵 | 種類ごとに公開範囲が違う |
| service_role key | Supabaseの強い管理用キー | ブラウザ・スマホ・GitHubに出さない |
| RLS | 行ごとのアクセス制御 | ユーザーのデータを分離する |
| 認証 | 本人かどうかを確認する仕組み | Googleログインなど |

## IncomeMate固有の用語

| 用語 | 意味 |
|---|---|
| 手渡し | 銀行振込ではなく現金でもらう収入 |
| 振込 | 銀行口座などへ入金される収入 |
| タイミー案件 | 案件ごとに仕事名・勤務時間・総額が変わる単発の仕事 |
| 予定収入 | シフト予定から計算した見込み額 |
| 実績収入 | 実際に働いた時間や受け取った金額 |
| 扶養上限 | 年間収入を確認するための設定値。制度や個人の状況で異なるため、最終判断は公的情報や専門家に確認する |

## 迷ったときの見分け方

- 画面の見た目を変える → UI / フロントエンド
- 保存場所やログインを変える → バックエンド / Supabase
- GitHubへ変更を残す → commit / push
- GitHubの変更をPCへ取り込む → pull
- 秘密情報を設定する → `.env`
- 一般公開前に人へ試してもらう → TestFlight、Google Playテスト、またはPWA共有
