# IncomeMateのコンセプト

IncomeMateは、掛け持ちアルバイトの収入管理を楽にするための個人用アプリです。

## 解決したい課題

複数のアルバイトをしていると、次のような情報がばらばらになります。

- 勤務先ごとの時給
- 月ごとの収入
- 振込と手渡しの違い
- タイミーのような案件ごとの報酬
- Googleカレンダー上のシフト予定
- 扶養上限までの残り金額

IncomeMateは、これらをひとつの場所にまとめて、「いまいくら稼いでいて、あといくら働けるのか」を見やすくすることを目指しています。

## 想定ユーザー

- 掛け持ちで複数のアルバイトをしている人
- 扶養上限を気にしながら働いている人
- タイミーや単発バイトも含めて収入を管理したい人
- スマホでシフトや収入を確認したい人

## 大切にする方針

- スマホで見やすい
- 入力の手間を減らす
- 手渡し収入も記録できる
- 個人情報を安全に扱う
- 初心者でも仕組みを理解しながら育てられる
